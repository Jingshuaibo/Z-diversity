# Z-diversity
R scripts and raw data for Z diversity

1.data
  The raw data for Z diversity test, including:
1)sim_occur_data: 36 simulated presence-absence matrices named as "dataxy.xlsx" (x: nestedness gradient; y: turnover gradient), 
  with speices as columns and site as rows 
2)abun(occur)_list.RData: simulated abundance and presence-absence species-site matrices stored in the form of RData file for use in R
3)empirical data: Bird(Butterfly)Data.xlsx: the species-site abundance matrices of birds and butterflies
  Bird(Butterfly)_info.xlsx: the family, species name and short name of each species
